# University Course Registration System

This is a simple Java-based university course registration system that uses core data structures such as linked lists and stacks. It simulates how students can enroll in and drop courses, and includes sorting functions to organize data.

## My Contributions

In this project, I:
- Implemented **two sorting functions** to organize student or course data.
- Built the **course enrollment** and **unenrollment** features.
- Designed and implemented a **stack** to support internal operations (such as undo/redo, history, or temporary storage).
- Worked with Java's OOP principles and data structures to maintain clean, modular code.

## Features
- Add, display, enroll, and drop courses
- Sort students or courses using custom algorithms
- Use of linked lists to store dynamic data
- Use of stack data structure
